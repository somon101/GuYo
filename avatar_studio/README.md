# Студия аватаров

Отдельная офлайн-программа на Flutter (Windows и Android) для сборки аватарок из деталей: одежда, шея, голова с лицом, очки, волосы, руки, фон и свои слоты. Не зависит от приложения, админки и сервера GuYo, интернет не нужен. Все данные хранятся на устройстве.

## Что умеет

- **Вырезалка**: лист с несколькими деталями → рамки (авто, ручные, сетка) → крупная правка кистью «Стереть»/«Вернуть», пипетка «Убрать цвет», зум двумя пальцами → «В слот». Код: `lib/core/sheet_split.dart`, `lib/core/mask_edit.dart`, `lib/ui/cutter.dart`.
- **Слоты и наборы.** У каждого слота своя точка на холсте (1200×1600) и точка привязки детали (верх, центр, низ). Положение задаётся числами, ползунками, перетаскиванием или кликом по макету и принадлежит слоту: любая другая деталь слота встаёт на то же место. Наборы это комплекты деталей, положение общее для всех наборов или отдельное для набора.
- **Фон картинки при загрузке: выбор.** Перед добавлением картинок окно спрашивает: «Вырезать фон автоматически» (чёрный, белый, «шахматка», однотонный; исходник сохраняется) или «Оставить как есть» (если вы вырезали фон сами). Выбор можно запомнить, потом поменять переключателем «Спрашивать / Вырезать / Как есть». У загруженной детали есть «Вырезать фон у выбранной» и «Вернуть как было».
- **Положение у каждой детали.** Стандарт слота задаётся один раз, у детали можно сохранить своё положение («Править положение детали»). Размер хранится как ширина в пикселях холста.
- **Поворот:** у слота и у детали отдельно (вокруг точки привязки), ползунок и кнопки ±1°.
- **История:** кнопки «Назад» и «Вперёд» (Ctrl+Z, Ctrl+Y).
- **Мужской и женский персонаж:** пол задаётся у детали (мужское, женское, оба), стандарты слотов у каждого пола свои.
- **Набор деталей:** «Загрузить набор деталей» принимает много файлов; имя вида `слот__пол__название.png` раскладывает деталь по слоту и полу (слоты: `bg`, `handL`, `handR`, `hand` (оба), `cloth`, `neck`, `face`, `glasses`, `hair`; пол: `male`, `female`, `both`). Листы с несколькими деталями делит `dart run tool/split_sheet.dart` (см. шапку файла).
- **Фон профиля:** готовые цвета и градиенты, свой цвет, своё фото (приближение и сдвиг).
- **Кадр профиля:** «Голова», «По пояс», «Весь» или свой, круг или скруглённый квадрат. Просмотр «в профиле» (шапка, рейтинг, чат) и PNG профиля.
- **Мои аватарки:** сохранённые сборки (детали, фон, кадр), сравнение рядом, PNG каждой.
- **Проект в файл** и обратно; PNG аватара без фона. Автосохранение. Светлая и тёмная темы. Компьютер: три колонки, телефон: сцена и вкладки.

## Запуск и сборка
```
cd avatar_studio
flutter pub get
flutter run -d windows      # или: flutter run (Android)
flutter test                # тесты
flutter build apk --release
flutter build windows --release
```
Готовые сборки по команде: workflow `Build Avatar Studio` (ручной запуск) кладёт `AvatarStudio.apk` и `Avatar-Studio-Windows.zip` в релиз `avatar-studio`.

## Устройство
- `lib/core/`: чистая логика (`geometry.dart` холст, слоты, кадр; `bg_removal.dart` вырезание фона; `model.dart` проект и JSON).
- `lib/state/`: `studio.dart` (состояние и операции), `render.dart` (рисование для сцены, миниатюр и PNG), `storage.dart` (проект JSON и картинки файлами), `services.dart` (системные окна выбора и сохранения файлов).
- `lib/ui/`: сцена, панели, окна, тема.
- Тесты: `test/core_test.dart` (логика), `test/studio_test.dart` (сценарии состояния), `test/ui_test.dart` (экраны); `test/screenshots_test.dart` делает снимки экранов для ручной проверки (`AS_SHOTS=папка AS_PARTS=папка_с_картинками`).

## Формат проекта (задел под будущую связь с сервером GuYo)
Файл `.json` с полем `format: "avatar-studio/1"`: слоты и порядок, положение слотов, наборы (детали с картинками в base64), кадр профиля, сохранённые аватарки. При несовместимых изменениях версия формата растёт, старые файлы поднимаются через `ProjectState.migrate`. Когда понадобится интеграция (отправка настроек и координат на сервер, подхват приложением), этот файл и есть готовый обмен.
