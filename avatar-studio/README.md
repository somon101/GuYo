# Студия аватаров

Отдельная офлайн-программа для сборки аватарок из деталей (одежда, голова с лицом, волосы, очки, руки, фон). Не зависит от приложения, админки и сервера GuYo, интернет не нужен. Все данные хранятся на устройстве.

## Что умеет
- Слоты (одежда, шея, голова с лицом, очки, волосы, руки, фон и свои), у каждого своя точка на холсте и точка привязки детали. Положение задаётся числами, ползунками, перетаскиванием или кликом по макету, и оно принадлежит слоту: любая другая деталь слота встаёт на то же место.
- Наборы деталей: в каждом свои варианты слотов. Положение слота общее для всех наборов или отдельное для набора.
- Загрузка картинок (PNG, JPEG, WebP). Фон (чёрный, белый, «шахматка», однотонный) вырезается автоматически при загрузке, можно повторить или вернуть исходную картинку.
- Фон профиля: готовые цвета и градиенты, свой цвет, своё фото (приближение и сдвиг).
- Кадр для профиля: «Голова», «По пояс», «Весь» или свой, круг или скруглённый квадрат. Просмотр «в профиле» (шапка, рейтинг, чат).
- «Мои аватарки»: сохранённые сборки (детали, фон, кадр), сравнение рядом, PNG каждой.
- Проект в файл и обратно, PNG аватара без фона, PNG профиля.
- Всё сохраняется само (IndexedDB). Светлая и тёмная тема. Компьютер и телефон (вкладки внизу сцены).

## Запуск
- **Браузер, без установки:** открыть `www/index.html` (двойной клик). Хранилище живёт в браузере.
- **Установка как приложение:** открыть сайт по адресу (https) в Chrome и выбрать «Установить»: оболочка кэшируется (`www/sw.js`), дальше работает без интернета.
- **Windows:** `npm install`, затем `npm start` (Electron) или `npm run dist:win` (portable exe).
- **Android:** `npm install`, `npx cap add android`, `npx cap sync android`, сборка в `android/` (Gradle). Файлы (PNG, проект) отдаются через системное окно «Поделиться».
- **Сборка по команде:** workflow `Build Avatar Studio` (ручной запуск) собирает `AvatarStudio.apk` и `Avatar-Studio.exe` и кладёт их в релиз `avatar-studio`.

## Проверки
- `npm test`: геометрия, кадр профиля, вырезание фона, формат проекта (`node --test`).
- `npm run smoke`: сквозная проверка в браузере (нужен `playwright`): загрузка, вырезание фона, сохранение после перезапуска, аватарки, PNG, проект в файл и обратно, телефон.

## Устройство
- `www/core.js`: чистая логика без DOM (холст 1200×1600, слоты, геометрия, `framePreset`, `removeBackground`, `migrate`).
- `www/db.js`: IndexedDB (`kv` для проекта, `blobs` для картинок).
- `www/app.js`: интерфейс; `www/index.html`, `www/style.css`, `www/sw.js`, `www/manifest.webmanifest`.
- `electron/main.js`: оболочка для компьютера, `capacitor.config.json`: оболочка для Android.

## Формат проекта (задел под будущую связь с сервером GuYo)
Файл `.json` с полем `format: "avatar-studio/1"`: слоты и порядок, положение слотов (`geo`), наборы (детали с картинками как data-URL, выбранные детали, свои положения), кадр профиля, сохранённые аватарки. Версия формата растёт при несовместимых изменениях, старые файлы поднимаются через `AS.migrate`. Когда понадобится интеграция (отправка настроек и координат на сервер, подхват приложением), этот файл и есть готовый обмен.
